# SmartGrid Sentinel Frontend

## Setup Instructions

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

## Features
- District/Upazila selection
- Weather display
- Risk level prediction
- Confidence distribution chart
- Operational recommendations

## Tech Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Recharts
- Axios
- Lucide Icons
